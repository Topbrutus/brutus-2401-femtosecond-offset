# Release Notes — v2.0.0

## Residual propagation

Version 1.0.0 was intentionally minimal: it documented one equation, its high-precision solution, and a strict boundary between mathematics and physical interpretation.

It was also produced during the author's first sustained attempt to formalize this kind of calculation in a reproducible scientific repository.

Since that first release, the working method has become more systematic. Version 2.0.0 therefore revisits the same construction without changing its original hypothesis and adds a missing piece: explicit propagation of the residual.

## Main result added in v2

Starting from

\[
f=240.1000000000576480100000138412872\ldots,
\]

the residual relative to \(240.1\) is

\[
\Delta f
=5.76480100000138412872\ldots\times10^{-11}.
\]

Multiplying both the reference and exact candidate by \(2401\) gives

\[
2401\times240.1=576480.1
\]

and

\[
2401f
=576480.1000001384128720100332329305696\ldots.
\]

Thus

\[
2401\Delta f
=1.3841287201003323293\ldots\times10^{-7}.
\]

The trailing digits at the scaled level are therefore traceable to the original residual. They are not introduced as an independent correction.

## Methodological change

The v2 workflow distinguishes explicitly between:

1. the declared reference value;
2. the exact candidate generated by the hypothesis;
3. the residual between them;
4. propagation of that residual through later algebraic operations;
5. physical interpretation, which remains a separate question.

## Scientific boundary

Version 2.0.0 does not claim a measured resonance, a new physical constant, or evidence for a relation to the Brout-Englert-Higgs boson. Such claims would require an independently defined physical model and experimental validation.

The purpose of v2 is narrower: preserve small deterministic terms and make their mathematical origin auditable.
